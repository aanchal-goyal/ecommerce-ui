# 🛒 ShopX – E-Commerce UI

A modern **frontend e-commerce user interface** built using **HTML, CSS, and JavaScript**.  
This project demonstrates common online shopping features such as product browsing, cart management, search and filtering, and a chatbot assistant.

---

## 🌐 Live Demo

https://aanchal-goyal.github.io/ecommerce-ui/

---

## ✨ Features

### 🛍 Product Catalog
- 10 products with multiple variations
- Categories: Headphones, Shoes, Smart Phones, Smart Watch
- Product images and pricing

### 🔍 Search & Filter
- Search products by name
- Filter products by category

### 🛒 Shopping Cart
- Add items to cart
- Increase / decrease quantity
- Remove items
- Checkout simulation
- Sliding cart panel

### 💾 Cart Persistence
- Cart saved using **localStorage**
- Items remain even after page refresh

### 🤖 Chatbot Assistant
- Interactive chatbot for basic customer help
- Suggests products and answers common questions

### 🎨 UI / UX
- Clean responsive product cards
- Smooth animations
- Modern layout

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)  
- localStorage API
